# Plan structure

Use only the sections relevant to the task.

| Section | Evidence to include |
|---|---|
| Goal and scope | Authorized outcome and non-goals |
| Source requirements | Named spec sections, ADRs and contracts |
| Prerequisites | Dependencies, blockers, approvals and existing baseline |
| Work sequence | Ordered tasks, likely affected files, contract changes |
| Acceptance | Expected behavior, error cases, security and compatibility checks |
| Verification | Actual project commands and supported environments |
| Risk and decisions | Alternatives, owner decisions, rollout or rollback where applicable |
| Completion | Executed evidence, remaining checks, unresolved decisions |

A plan-only request stops at the plan. A plan is not proof of execution.
Do not assume unanswered questions are approved or add numeric acceptance
thresholds that the specification does not contain.
