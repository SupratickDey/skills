Tests include a store or wrapper where another writer changes the row between
the read and the write and assert Conflict with the other write preserved,
plus insufficient stock, unknown SKU and a successful reservation. The agent
runs the relevant Cargo checks (build, tests and clippy at the project lint
level or -D warnings when none is configured), reports the actual outcomes,
and does not claim a command passed that it did not run or that failed.
